# Mac 超长会话与断点续跑验收（2026-11-13）

本轮接续 `45b1715` 的短、中会话真实模型验收。用户明确允许超长任务闲时或手动后台运行。沿用同一台 Mac、DSH `0.2.1-rc.5`、`~/.dsh` 的 `web` profile，以及 DSH 配置的 `openai-codex / gpt-6-astra`；不新增服务或凭证。原文、模型输出和诊断记录只保存在本地。

## 实验记录

1. **假设：整体十分钟限制和不保存中间结果使长会话无法可靠完成。** 移除整个任务的截止时间，保留单次模型调用 90 秒限制；将通过校验的分片及合并输出逐批持久化。原文指纹、模型路由、解析版本和批次输入均一致时才续跑。暂停、存储失败、传输失败和重启回归通过，旧报告与原文未被清除。保留。
2. **假设：真实宿主重启后可复用已完成批次。** 早期候选构建保存 7 步后暂停、完全退出宿主并重启；界面显示继续解析，恢复后复用 7 步并发起后续真实模型调用。没有把这一局部结果作为完整长会话通过。
3. **假设：工具结果中包含尚未计入的人类表达。** 对真实长会话的工具调用与结果按 callId 配对，确认 7 次问答控件提交，全部为成功提交，其中一次包含两项回答。原转换将它们归入 AI 节点。暂停长任务，补充严格的调用、问题 ID、提交结构校验，保留每次提交为独立人节点，并保存完整原事件；pending、错误和不匹配工具结果不冒充人的表达。进一步根据已安装 DSH 的原生实现，补齐 user-question-reply 迟到提交的严格匹配；该分支通过确定性边界测试，当前真实长样本没有此类事件。保留修复，旧解析边界的进度失效，不混用旧摘要。
4. **假设：新增断点表会影响已有 v1 数据。** 用真实 DSH 存储后端写入旧版报告和原文，再增加断点、关闭重开、删除断点并再次重开；报告及原文逐字段一致。保持 domain 版本 1，新增表和可选 jobId；不清空或重建用户存储。保留。
5. **假设：长任务慢主要是短记录各占一个分片。** 真实样本共 1,536,090 字符，1,708 条记录中 1,111 条不足 300 字。离线逐字重组测算：同节点按序合装，并把 seq/type/role/offset 及 JSON 转义计入 2,400 字符预算，可由 2,093 片、1,219 次调用降至 784 片、447 次。只增大片而不合装，收益很小。采用保持原单次内容预算的合装方案，并计划最多三路并发；此测算没有调用模型，不能作为摘要质量通过。串行候选在 37 个保存批次处暂停，其进度和存储备份保留；新分片规则必须使用新解析版本，不能混用旧摘要。
6. **假设：真实模型可能只遗漏 JSON 外层闭合符。** 并行构建在 `整理片段 64 / 784 · 格式纠正 2/2` 以 `$ / INVALID_JSON` 停止，已保存 17 步。使用同一 DSH 实例的临时诊断 overlay、同一宿主 rc.5 装配器和完全相同模型参数重放该四片输入：首次响应 767 字符、428 输出 token，完整流以 stop 结束，所有 text-delta 与装配文本逐字一致。四个条目均完整，仅遗漏最外层 `]}`；原样追加这两字符后，现有全部 ID、摘要、细节校验通过。第二次原有纠正流程返回完整合法 JSON。此证据只确认捕获重放的根因，不能推定先前三次未捕获响应都相同。诊断未改 profile、凭证或正式插件，原文只存本地；正在补窄范围格式兼容测试。

## 长会话语义复核发现（仍存在）

错误集中于两类：程序切片被误解为原始材料缺失，及历史/引用内容被误当当前行动。具体包括完整工具参数被写为不完整、已返回的链式命令验证被写为未知、自动压缩上下文中的旧中断被算作当前事件、对比面板内历史条目的未知状态被转移给当前对比操作，以及旧工具结果的替换记录被当成新读取。

原始事件实际上保有工具调用关系、轮次和 `surfaceOp` 替换来源，但旧分片只发送 seq/type/role/offset/text，后续合并只接收摘要和细节。使用同一 DSH 模型重放 9 个原始批次，确认一段工具结果跨片后，首片产生“语法检查结果尚不可见”，后一片只保留测试通过；后续摘要已失去消除这项局部未知所需的证据关系。另一些首层输出正确保留了历史或引用限定，而最终合并丢失了限定。没有修改生成结果来绕过验收。

用户随后将产品主线明确为“看清自己的表达与介入，重点是介入之前”，因此本轮新增不调用模型的人的表达索引和按需前文阅读。来源关系在这个只读入口中保留，介入前查询不引入之后才出现的结果。完整轨迹仍保留为辅助入口，但其上述长样本语义偏差尚未修复；新的原文阅读验收不等于全量摘要语义通过。新的验收见[人的表达与前文阅读](human-reading-validation-2026-11-13.md)。

## 行为边界

解析仍由用户手动选择和启动，可离开插件页面；本轮没有新增闲时自动调度。任务不再受总时长限制，但必须保持 DSH 宿主运行。停止或退出后手动继续，可能重做尚未成功保存的当前批次。输入、模型路由或解析规则改变时重新开始；不将不同证据或不同规则的结果混合。模型仍执行原有输出校验和最多两次格式纠正，不截断、不确定性替代摘要，也不丢弃长日志尾部。
